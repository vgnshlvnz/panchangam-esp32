# Host build and tests

Everything here runs on a normal Linux machine with `gcc` and `make`. No
ESP-IDF is needed.

## Get the source

The Swiss Ephemeris is a git submodule:

```sh
git clone --recurse-submodules https://github.com/vgnshlvnz/panchangam-esp32.git
# or, in an existing clone:
git submodule update --init
```

## Compare the C port with the Python reference

```sh
make test
```

This builds `build/compare` from `core/panchangam.c` plus the Swiss Ephemeris
sources, and runs it over `test/reference.json`. To use another file:

```sh
make test REF=test/reference_hand.json
```

Expected result on the shipped reference:

```
750 case(s): 0 index/count mismatch(es), 0 time mismatch(es) (tolerance 2.0 s)
```

A case fails when an anga index or list length differs, or any instant differs
by more than 2 seconds. The exit status is non-zero on any mismatch.

`reference.json` covers Petaling Jaya (3.1073, 101.6067) for every day of 2026
and 2027 plus 20 random dates between 1950 and 2050. `reference_hand.json` is a
small hand-made Kuala Lumpur set.

## Swiss Ephemeris smoke test

```sh
make -C test smoke
./test/smoke
```

Builds a static `test/build/libswe.a` from the library sources (not the
programs with their own `main()`, such as `swetest.c`), then checks Sun and Moon
sidereal (Lahiri, Moshier) longitudes at three dates against values generated by
Python. Tolerance is 0.001 degrees. This confirms the two Swiss Ephemeris builds
agree before you look at anything higher up.

## Validate the reference file

```sh
python3 test/validate_reference.py
```

Checks `reference.json` against `test/SCHEMA.md`: structure, contiguous spans,
first span starting at or before sunrise, last span ending at or after the next
sunrise, and rahu kalam, yamagandam and gulika each being the right eighth of
daylight.

## Clean

```sh
make clean
make -C test clean
```

## Troubleshooting

- **Swiss Ephemeris files missing:** run `git submodule update --init`.
- **Mismatch only on old dates:** the reference uses the zone's historical
  offsets. `Asia/Kuala_Lumpur` was not UTC+8 before 1982.
- **Smoke test passes but `make test` fails:** the difference is in the
  panchangam logic in `core/panchangam.c`, not in the ephemeris.
